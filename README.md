# exam-notes-reader

Генератор офлайн-читалки конспектов к экзаменам: папка markdown-файлов «один вопрос — один файл»
превращается в **один HTML-файл**, который открывается на телефоне без интернета и без установки.
Сделал для своей подготовки к сессии: конспекты пишутся в Markdown, а повторять их удобно с телефона —
коротко перед ответом и подробно накануне.

[`demo/demo.html`](demo/demo.html) — пример на вымышленном курсе «Основы Python» (5 вопросов).
Скачайте файл и откройте в браузере телефона или компьютера.

## Что умеет читалка

- Два режима ответа: **«Кратко»** — 5–7 предложений, которые можно сказать преподавателю,
  и **«Подробно»** — план, разбор, термины, цитаты, даты, источники.
- **Поиск** по всем вопросам с учётом окончаний («функция» найдёт и «функции», и «функциями»),
  точная фраза в кавычках, номер вопроса — переход к нему; подсветка совпадений.
- **«Проверь себя»** — случайные вопросы, отметки «знаю / повторить», прогресс по предмету.
- **Словарь терминов** и **хронология** — собираются автоматически из всех вопросов.
- Ключи к **тестам** — из папки `Тесты/`.
- Настройки чтения: размер шрифта, интервал, светлая, тёмная или авто-тема, шрифт с засечками
  или без. Отметки и настройки хранятся только в этом браузере (`localStorage`).
- Общий файл по нескольким предметам с табло сессии: какие формы контроля и что осталось.
- Никаких внешних запросов по умолчанию: шрифты системные (запасной вариант — `system-ui`);
  с флагом `--webfonts` подключаются Literata и Old Standard TT из Google Fonts.

## Быстрый старт

Нужен Python 3.8+, сторонние пакеты не нужны.

```bash
python scripts/build_html.py "demo/Основы Python" --out demo/demo.html
python scripts/build_html.py "demo/Основы Python" --check --min-full 1500   # только отчёт, без записи
python -m unittest discover -s tests                                         # тесты
```

## Структура папок

```
<корень>/
  _Сессия.md                         табло сессии для общего файла (необязательно, пример — docs/)
  <Предмет>/
    Конспект/
      _Вопросы.md                    строки «Название: …», «Курс: …», «Охват: …» — в шапку читалки
      Вопросы/
        01. Короткое название.md     один вопрос — один файл
        02. …
    Тесты/*.md                       ключи к тестам (необязательно)
    Лекции/NN. *.md                  исходные лекции для lecture_digest.py (необязательно)
```

Формат файла вопроса — [`docs/формат-вопроса.md`](docs/формат-вопроса.md). Коротко:

```markdown
# Полный заголовок вопроса
Раздел: Тема 1. Название темы
Занятия: 1, 2
Ключевые слова: синонимы, термины, имена — поиск учитывает их с повышенным весом

## Кратко
5–7 предложений.
## План ответа
## Подробно
## Термины
- **Термин** — определение
## Цитаты
## Уточнения
**Вероятный вопрос преподавателя?** Короткий ответ.
## Даты
- 1991 — событие
## Источники
```

## Команды

| Команда | Что делает |
|---|---|
| `build_html.py <Предмет>` | `<корень>/Конспекты/<Предмет>.html` |
| `build_html.py <Предмет> --out файл.html` | то же, в указанный файл |
| `build_html.py --all <корень>` | читалка по каждому готовому предмету и общий `Все предметы.html` |
| `--only "А,Б"` | с `--all`: в общий файл только названные предметы |
| `--check` | отчёт по вопросам (число предложений в «Кратко», объём «Подробно», нет ли разделов) без записи файлов |
| `--min-full N` | порог «Подробно короткий» для отчёта, по умолчанию 2500 знаков |
| `--kratko` | дополнительно версия только с краткими ответами |
| `--webfonts` | подключить веб-шрифты (нужен интернет при открытии) |
| `--artifact файл` | дополнительно фрагмент без `<html>/<head>/<body>` для публикации как Claude Artifact |

`scripts/lecture_digest.py <Предмет>` — сводка по выгруженным лекциям (`Лекции/NN. *.md`):
объём, разделы, вопросы для самоконтроля и литература по каждой лекции плюс сводный список
литературы. Нужна, чтобы спланировать вопросы, не читая сначала сотни килобайт текста.

## Как это устроено

`build_html.py` разбирает markdown (ровно то подмножество, которым пишутся конспекты: заголовки,
списки, таблицы, цитаты, блоки кода, ссылки), собирает все предметы в JSON и подставляет его
в шаблон `assets/reader.html`. Шаблон — одна страница на ванильном JS без зависимостей:
маршруты по `#hash`, поиск, режимы, «Проверь себя», настройки. Итоговый файл самодостаточен.

## English summary

**exam-notes-reader** turns a folder of Markdown exam notes (one question per file, with sections
such as *Short answer*, *Plan*, *Full answer*, *Terms*, *Dates*, *Follow-up questions*) into a single
self-contained offline HTML reader for phones. Features: short/full answer modes, full-text search
with Russian stemming and highlighting, a self-check mode with progress tracking, an auto-built
glossary and timeline, test answer keys, reading settings and dark mode. No external requests by
default (system fonts with a `system-ui` fallback; web fonts are opt-in via `--webfonts`).
Python standard library only. Try `demo/demo.html` (a fictional "Python basics" course);
run tests with `python -m unittest discover -s tests`. The UI and the note format are in Russian.
