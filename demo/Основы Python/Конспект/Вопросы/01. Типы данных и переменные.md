# Типы данных и переменные в Python
Раздел: Тема 1. Введение в язык
Занятия: 1, 2
Ключевые слова: переменная, тип, int, float, str, bool, None, динамическая типизация, type, isinstance, изменяемость

## Кратко
Переменная в Python — это имя, которое ссылается на объект в памяти, а не ячейка с фиксированным типом. Тип принадлежит объекту, поэтому одно и то же имя можно связать сначала с числом, а потом со строкой: это называется динамической типизацией. Базовые встроенные типы — целые числа int, числа с плавающей точкой float, строки str, логический тип bool и особое значение None. Узнать тип объекта можно функцией type, а проверить принадлежность типу — функцией isinstance. Важно различать изменяемые и неизменяемые объекты: числа и строки неизменяемы, поэтому любая «правка» строки создаёт новый объект. При этом типизация в Python строгая: сложить строку с числом без явного преобразования нельзя.

## Подробно
### Имя и объект
В Python присваивание `x = 10` не кладёт число в «ячейку x». Интерпретатор создаёт объект-число 10 и связывает с ним имя x. Если затем написать `y = x`, оба имени будут указывать на один и тот же объект; это легко проверить функцией `id` или оператором `is`. Такое устройство объясняет многие особенности языка, в том числе поведение изменяемых коллекций, о которых речь пойдёт во втором вопросе.

### Динамическая, но строгая типизация
Тип хранится у объекта, а не у имени. Поэтому код `x = 10`, а следом `x = "десять"` совершенно законен: имя просто переключилось на другой объект. Это и называют динамической типизацией. Строгость проявляется в другом: Python не преобразует типы молча. Выражение `"5" + 5` вызовет ошибку `TypeError`, и программисту придётся явно написать `int("5") + 5` или `"5" + str(5)`. Так язык защищает от тихих ошибок, характерных для слабо типизированных языков.

### Базовые типы
- **int** — целые числа произвольной длины: переполнения, как в C, нет, Python сам выделит нужную память.
- **float** — числа с плавающей точкой двойной точности; отсюда классический пример `0.1 + 0.2 != 0.3`. Для денег используют `decimal.Decimal`.
- **str** — строки Unicode, неизменяемые последовательности символов.
- **bool** — `True` и `False`; это подкласс int, поэтому `True + True == 2`.
- **None** — единственный объект типа NoneType, означает «значения нет». Сравнивают с ним через `is None`.

### Проверка типа
`type(obj)` возвращает точный класс объекта. `isinstance(obj, cls)` отвечает, является ли объект экземпляром класса или его наследника, и потому предпочтительнее в проверках: `isinstance(True, int)` даст `True`, а `type(True) is int` — `False`. С версии 3.5 в язык добавлены аннотации типов (`def f(x: int) -> str`), но интерпретатор их не проверяет: это подсказки для читателя и для внешних анализаторов вроде mypy.

### Изменяемость
Неизменяемые объекты (int, float, str, tuple, frozenset) нельзя поменять «на месте». Операция `s += "!"` для строки создаёт новую строку и перепривязывает имя. Изменяемые объекты (list, dict, set) меняются на месте, и это изменение видно через все имена, которые на них ссылаются.

## Термины
- **Переменная** — имя, связанное с объектом в памяти.
- **Динамическая типизация** — тип определяется объектом во время выполнения, а не объявлением имени.
- **Строгая типизация** — отсутствие неявных преобразований между несовместимыми типами.
- **Неизменяемый объект** — объект, состояние которого нельзя изменить после создания.

## Уточнения
**Чем `is` отличается от `==`?** `==` сравнивает значения, `is` — идентичность объектов, то есть указывают ли два имени на один объект.

**Почему `0.1 + 0.2` не равно `0.3`?** Двоичная дробь не может точно представить 0,1; накапливается ошибка округления. Сравнивают через `math.isclose`.
