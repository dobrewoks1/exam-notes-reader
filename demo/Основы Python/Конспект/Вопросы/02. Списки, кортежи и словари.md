## Кратко
В Python есть три основные коллекции: список list, кортеж tuple и словарь dict. Список — изменяемая упорядоченная последовательность, в него можно добавлять и удалять элементы. Кортеж похож на список, но неизменяем, поэтому годится как ключ словаря и как «запись» из нескольких полей. Словарь хранит пары «ключ — значение» и находит значение по ключу в среднем за постоянное время благодаря хеш-таблице. Ключом словаря может быть только хешируемый, то есть фактически неизменяемый, объект. Выбор коллекции зависит от задачи: порядок и правки — список, фиксированная запись — кортеж, быстрый поиск по ключу — словарь.

## Подробно
### Список
Список создаётся квадратными скобками: `nums = [3, 1, 2]`. Элементы доступны по индексу с нуля, отрицательный индекс считает с конца: `nums[-1]` вернёт последний элемент. Срез `nums[1:3]` возвращает новый список из элементов с индексами 1 и 2. Основные методы: `append` добавляет элемент в конец, `extend` — элементы другой последовательности, `insert` — в произвольную позицию, `pop` удаляет и возвращает элемент, `sort` сортирует на месте. Добавление в конец работает быстро, а вставка в начало требует сдвига всех элементов, поэтому для очереди лучше подходит `collections.deque`.

### Кортеж
Кортеж записывается через запятую, обычно в круглых скобках: `point = (10, 20)`. Изменить его элементы нельзя, зато кортеж хешируем, если хешируемы все его элементы, и поэтому может быть ключом словаря или элементом множества. Кортежи удобно распаковывать: `x, y = point`. Для записей с именованными полями есть `collections.namedtuple` и `typing.NamedTuple`, которые делают код понятнее, чем обращение по индексу.

### Словарь
Словарь — это отображение ключей на значения: `ages = {"Анна": 30, "Борис": 25}`. Обращение `ages["Анна"]` вернёт 30, а отсутствующий ключ вызовет `KeyError`; чтобы получить значение по умолчанию, используют `ages.get("Вера", 0)`. Внутри словарь устроен как хеш-таблица: по хешу ключа вычисляется место хранения, поэтому поиск, вставка и удаление в среднем выполняются за O(1). Начиная с Python 3.7 словарь гарантированно сохраняет порядок вставки. Перебор `for k, v in ages.items()` даёт пары ключ — значение.

### Копирование
Присваивание `b = a` не копирует список, а создаёт второе имя для того же объекта. Поверхностная копия `a.copy()` или `a[:]` создаёт новый список, но вложенные объекты остаются общими. Если внутри списка лежат другие списки и их нужно скопировать полностью, используют `copy.deepcopy`.

### Множество
Отдельно стоит множество `set` — неупорядоченная коллекция уникальных элементов с быстрыми операциями объединения, пересечения и проверки вхождения. Оно полезно, когда нужно убрать дубликаты или быстро проверить, встречался ли элемент.

## Термины
- **Хешируемый объект** — объект с неизменным хешем, который можно использовать как ключ словаря.
- **Срез** — выражение вида `seq[start:stop:step]`, возвращающее часть последовательности.
- **Поверхностная копия** — новая коллекция с теми же вложенными объектами.

## Уточнения
**Почему список не может быть ключом словаря?** Список изменяем, его хеш мог бы поменяться после вставки, и словарь потерял бы ключ.

**Как перевернуть список?** `lst.reverse()` на месте или `lst[::-1]` — новым списком.
