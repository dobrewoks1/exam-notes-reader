# Условные операторы и циклы
Раздел: Тема 3. Управление потоком
Занятия: 5
Ключевые слова: if, elif, else, for, while, break, continue, range, enumerate, отступ, истинность

## Кратко
Ход выполнения программы в Python управляется условным оператором if и двумя циклами — for и while. Блоки кода выделяются не скобками, а отступом, обычно в четыре пробела, и это часть синтаксиса языка. Оператор if проверяет условие, ветки elif добавляют альтернативы, а else срабатывает, если ни одно условие не выполнилось. Цикл for перебирает элементы любой итерируемой коллекции, а для счётчика используют range. Цикл while повторяется, пока условие истинно, и требует следить, чтобы оно когда-нибудь стало ложным. Операторы break и continue позволяют досрочно выйти из цикла или перейти к следующей итерации.

## Подробно
### Отступы
В Python границы блока определяются отступом. Все строки одного блока должны иметь одинаковый отступ; смешение табуляций и пробелов приводит к ошибке `TabError`. Руководство по стилю PEP 8 рекомендует четыре пробела. Благодаря этому код на Python выглядит единообразно: структура программы видна сразу.

### Условный оператор
```
if score >= 90:
    grade = "отлично"
elif score >= 70:
    grade = "хорошо"
else:
    grade = "нужно подтянуть"
```
Условием может быть любое выражение. Ложными считаются `False`, `None`, ноль, пустая строка и пустые коллекции; всё остальное истинно. Поэтому проверку на пустоту пишут коротко: `if items:` вместо `if len(items) > 0:`. Для коротких выборов есть условное выражение `x = a if cond else b`.

### Цикл for
Цикл for в Python перебирает элементы, а не индексы: `for name in names:`. Если нужен номер, используют `enumerate`: `for i, name in enumerate(names, start=1):`. Для последовательности чисел есть `range(start, stop, step)`; верхняя граница не включается. Перебирать можно строки, словари, файлы и любые объекты, реализующие протокол итерации.

### Цикл while
`while` повторяет тело, пока условие истинно. Типичная ошибка — забыть изменить переменную условия и получить бесконечный цикл. Иногда бесконечный цикл нужен сознательно: `while True:` с выходом через `break`, например при чтении команд пользователя до слова «выход».

### break, continue и else
`break` немедленно прерывает ближайший цикл, `continue` пропускает остаток текущей итерации. Необычная деталь Python — ветка `else` у цикла: она выполняется, если цикл завершился естественно, без `break`. Это удобно для поиска: если элемент не найден и цикл дошёл до конца, срабатывает `else`.

## Термины
- **Итерируемый объект** — объект, который можно перебрать в цикле for.
- **Истинность** — правило, по которому любое значение трактуется как True или False в условии.

## Уточнения
**Как пройти два списка одновременно?** Функцией `zip`: `for a, b in zip(xs, ys):`.

**Есть ли в Python switch?** С версии 3.10 есть оператор сопоставления `match … case`.
