# Функции и область видимости
Раздел: Тема 4. Функции

Ключевые слова: def, return, аргумент, параметр, args, kwargs, lambda, LEGB, global, nonlocal, замыкание

## Кратко
Функция в Python объявляется словом def, принимает параметры и возвращает результат оператором return. Если return не указан, функция возвращает None. Параметры бывают позиционными и именованными, у них могут быть значения по умолчанию, а конструкции args и kwargs собирают произвольное число аргументов. Имена ищутся по правилу LEGB: сначала локальная область, затем объемлющая функция, затем глобальная область модуля и в конце встроенные имена. Чтобы изменить глобальную переменную внутри функции, нужно объявить её через global, а переменную объемлющей функции — через nonlocal. Функции в Python — полноценные объекты: их можно передавать как аргументы, возвращать из других функций и хранить в коллекциях.

## Подробно
### Объявление
```
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"
```
Вызов `greet("Анна")` вернёт «Привет, Анна!», а `greet("Анна", greeting="Здравствуйте")` — вариант с другим приветствием. Хорошая функция делает одно дело, имеет понятное имя и строку документации в первой строке тела.

### Параметры и аргументы
Параметры — это имена в объявлении, аргументы — значения при вызове. Аргументы можно передавать позиционно или по имени. Значение по умолчанию вычисляется один раз, при определении функции, поэтому изменяемое значение по умолчанию — классическая ловушка: `def add(x, acc=[])` будет накапливать элементы между вызовами. Правильно писать `acc=None` и внутри создавать новый список.

### *args и **kwargs
Параметр со звёздочкой `*args` собирает лишние позиционные аргументы в кортеж, а `**kwargs` — лишние именованные в словарь. Это позволяет писать обёртки и функции с переменным числом аргументов. Те же звёздочки при вызове распаковывают коллекции: `f(*items, **options)`.

### Области видимости: LEGB
Когда интерпретатор встречает имя, он ищет его последовательно в четырёх областях: Local — внутри текущей функции, Enclosing — во внешних функциях, Global — на уровне модуля, Built-in — среди встроенных имён вроде `len` и `print`. Присваивание внутри функции по умолчанию создаёт локальное имя. Объявление `global counter` позволяет изменить переменную модуля, а `nonlocal` — переменную объемлющей функции. Злоупотреблять global не стоит: явная передача значений через параметры делает код предсказуемее.

### Функции как объекты
Функцию можно присвоить переменной, передать в `sorted(items, key=len)` или вернуть из другой функции. Короткие безымянные функции записывают через `lambda`: `lambda x: x * 2`. Вложенная функция, которая запоминает переменные внешней, называется замыканием; на замыканиях построены декораторы — функции, которые оборачивают другие функции и добавляют им поведение.

## Термины
- **Параметр** — имя в объявлении функции.
- **Аргумент** — значение, переданное при вызове.
- **Замыкание** — функция, сохраняющая доступ к переменным объемлющей области после её завершения.
- **Декоратор** — функция, принимающая функцию и возвращающая её изменённую версию.

## Уточнения
**Передаются ли аргументы по ссылке или по значению?** Передаётся ссылка на объект: изменяемый объект можно поменять внутри функции, а перепривязка имени снаружи не видна.

**Можно ли вернуть несколько значений?** Да, через кортеж: `return a, b`, а при вызове — распаковать.
