# Исключения и работа с файлами
Раздел: Тема 5. Надёжный код
Занятия: 8
Ключевые слова: try, except, else, finally, raise, исключение, with, open, контекстный менеджер, кодировка, pathlib

## Кратко
Ошибки во время выполнения программы Python сообщает исключениями, и их перехватывают конструкцией try и except. Перехватывать стоит конкретные классы исключений, например ValueError или FileNotFoundError, а не все подряд. Ветка else выполняется, если исключения не было, а finally — всегда, и там освобождают ресурсы. Собственное исключение возбуждают оператором raise. Файлы открывают функцией open внутри оператора with: контекстный менеджер закроет файл даже при ошибке. Для текстовых файлов кодировку нужно указывать явно, обычно utf-8, иначе результат зависит от настроек системы.

## Подробно
### Исключения
Исключение — объект, который сигнализирует об ошибке и прерывает обычный ход программы. Если его никто не перехватил, программа завершится и напечатает трассировку. Все стандартные исключения наследуются от `BaseException`, а пользовательский код работает с потомками `Exception`: `ValueError` (неверное значение), `TypeError` (неверный тип), `KeyError` и `IndexError` (нет ключа или индекса), `FileNotFoundError` (нет файла).

### Перехват
```
try:
    n = int(text)
except ValueError:
    print("Это не число")
else:
    print("Получили", n)
finally:
    print("Проверка завершена")
```
Ветка `except` ловит только указанные классы и их потомков. Пустой `except:` перехватывает вообще всё, включая прерывание с клавиатуры, и прячет настоящие ошибки, поэтому так писать не рекомендуется. Несколько классов перечисляют кортежем: `except (ValueError, TypeError) as e:`. Объект исключения доступен через `as`.

### Возбуждение исключений
`raise ValueError("возраст не может быть отрицательным")` возбуждает исключение с сообщением. Собственный класс создают наследованием: `class ConfigError(Exception): pass`. Внутри `except` можно написать `raise` без аргументов, чтобы пробросить исключение дальше, или `raise NewError(...) from e`, чтобы сохранить причину.

### Файлы
Функция `open(path, mode, encoding=...)` открывает файл. Режимы: `"r"` — чтение, `"w"` — запись с очисткой, `"a"` — дозапись, `"b"` — двоичный режим. Для текстовых файлов кодировку указывают явно: `encoding="utf-8"`; без неё на Windows по умолчанию может использоваться другая кодировка, и кириллица превратится в нечитаемые символы.

### with и pathlib
Оператор `with open("data.txt", encoding="utf-8") as f:` гарантирует закрытие файла при выходе из блока, даже если внутри произошло исключение. Это частный случай контекстного менеджера — объекта с методами `__enter__` и `__exit__`. Модуль `pathlib` даёт объектный интерфейс к путям: `Path("data") / "report.txt"`, `path.read_text(encoding="utf-8")`, `path.exists()`; такой код одинаково работает на Windows и Linux.

## Термины
- **Исключение** — объект, сигнализирующий об ошибке во время выполнения.
- **Трассировка** — отчёт о цепочке вызовов, приведших к необработанному исключению.
- **Контекстный менеджер** — объект, который управляет ресурсом в блоке with.

## Уточнения
**Когда использовать finally, а когда with?** with — для ресурсов, у которых есть контекстный менеджер (файлы, блокировки); finally — для остальных действий, которые должны выполниться всегда.

**Как прочитать большой файл, не загружая его целиком?** Перебирать строки в цикле: `for line in f:`.
