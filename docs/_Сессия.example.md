# Зимняя сессия

Пример табло для общего файла (`build_html.py --all <корень>`). Положите копию в корень как `_Сессия.md`.
Строки с «да» в последней колонке и готовыми вопросами входят в «Все предметы.html» в этом порядке;
остальные показываются на табло как тихие карточки.

| Папка | Название | Форма | Что нужно | В сборку |
|---|---|---|---|---|
| Основы Python | Основы Python | экзамен | 5 вопросов, устно | да |
| Базы данных | Базы данных | зачёт | тест на 20 вопросов | да |
| Английский язык | Английский язык | ждём | вопросы ещё не выдали | нет |
