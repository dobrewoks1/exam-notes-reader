# Формат файла вопроса

Файл: `<Предмет>/Конспект/Вопросы/NN. Короткое название.md` (NN — две цифры). Его разбирает `build_html.py`; заголовки разделов распознаются и в вариантах (например, «Если спросят» = «Уточнения», «Хронология» = «Даты»).

```
# Полный заголовок вопроса
Раздел: Тема N. Название темы
Занятия: 12
Ключевые слова: слово, фраза, имя, …

## Кратко
5–7 предложений (--check допускает 5–8), прямая речь студента преподавателю, ~900–1500 знаков.
## План ответа
1. …
## Подробно
### Подразделы… (таблицы, списки — где уместно; обычно 6–12 тыс. знаков)
## Термины
- **Термин** — определение
## Цитаты
> «…» (ссылка)
## Уточнения
**Вероятный вопрос преподавателя?** Короткий ответ.

**Следующий вопрос?** Ответ.
## Даты
- 1659 — событие
## Источники
- Занятие N. «…» — лекция курса.
- Книга, глава — URL
```

Правила разметки:
- В «Датах» строго «дата — событие» (длинное тире с пробелами) — иначе дата не попадёт в хронологию.
- Между пунктами «Уточнений» — пустая строка.
- «Ключевые слова» — синонимы и смежные понятия, по которым студент будет искать (имена, термины, греческие слова): поиск в читалке учитывает их с повышенным весом.
- Ключи тестов: `<Предмет>/Тесты/*.md` подхватываются в раздел «Тесты» автоматически.
- `_Вопросы.md`: строки `Курс: …` и `Охват: …` идут в шапку читалки.
